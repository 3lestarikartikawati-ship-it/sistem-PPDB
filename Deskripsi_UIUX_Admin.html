a. Tampilan Pesan dari Pendaftar
[ Sisipkan Gambar Halaman Pesan dari Pendaftar Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Pesan dari Pendaftar pada dasbor Administrator. Halaman ini berfungsi sebagai kotak masuk (inbox) terpusat di mana admin dapat memantau dan membalas pesan serta konsultasi yang dikirimkan oleh calon pendaftar. Desainnya dibuat bersih dan minimalis untuk memastikan admin dapat fokus pada pengelolaan pesan yang masuk tanpa gangguan visual yang tidak perlu.

b. Tampilan Manajemen FAQ
[ Sisipkan Gambar Halaman Manajemen FAQ Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Manajemen FAQ (Frequently Asked Questions). Halaman ini memungkinkan admin untuk mengelola daftar pertanyaan yang sering diajukan untuk nantinya ditampilkan di halaman depan (landing page) publik. Antarmuka menggunakan struktur tabel standar yang menampilkan urutan, pertanyaan, jawaban, serta kolom aksi (Edit dan Hapus), dilengkapi dengan tombol panggilan aksi (Call to Action) yang jelas untuk menambahkan FAQ baru.

c. Tampilan Pengaturan Sistem PPDB
[ Sisipkan Gambar Halaman Pengaturan Sistem PPDB Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Pengaturan Sistem PPDB. Melalui antarmuka ini, administrator diberikan kewenangan penuh untuk mengendalikan jalannya proses pendaftaran. Desain form diatur secara horizontal yang mencakup pengaturan krusial seperti status pendaftaran (buka/tutup) dan penentuan total kuota keseluruhan gelombang. Tata letak ini memberikan kemudahan bagi admin untuk melakukan pembaruan kebijakan secara instan.

d. Tampilan Manajemen Keuangan dan Daftar Ulang
[ Sisipkan Gambar Halaman Keuangan dan Daftar Ulang Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Keuangan dan Daftar Ulang. Bagian atas halaman menyajikan kartu ringkasan informasi (summary cards) yang menyoroti metrik penting seperti jumlah siswa diterima, status kelunasan, dan total uang terkumpul. Pada bagian bawah, terdapat tabel data pembayaran yang komprehensif, dilengkapi dengan fitur ekspor data (PDF/CSV) untuk mempermudah panitia dalam melakukan rekapitulasi dan pelaporan keuangan.

e. Tampilan Pembagian Kelas Siswa (Plotting Rombel)
[ Sisipkan Gambar Halaman Pembagian Kelas Siswa Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Pembagian Kelas Siswa (Plotting Rombongan Belajar). Antarmuka ini dirancang dengan tata letak dua area utama (split view). Sisi kiri digunakan untuk menyeleksi siswa yang telah lunas daftar ulang dan memasukkannya ke kelas tertentu, sedangkan sisi kanan menampilkan daftar kelas yang sudah terbentuk (rombel) beserta opsi untuk mencetak daftar siswa per kelas. Desain ini sangat ergonomis untuk memproses pemindahan data secara massal maupun individu.

f. Tampilan Halaman Login Admin
[ Sisipkan Gambar Halaman Login Admin Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Login Admin. Halaman ini merupakan pintu gerbang keamanan utama bagi pengelola sistem. Desain difokuskan di tengah layar (center-aligned) untuk memberikan penekanan penuh pada proses autentikasi. Terdapat form input terpusat untuk memastikan administrator dapat mengakses dasbor kendali dengan mudah, fokus, dan aman.

g. Tampilan Dashboard Admin
[ Sisipkan Gambar Dashboard Admin Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Dashboard Admin. Halaman ini bertindak sebagai pusat kendali utama (command center) bagi administrator. Bagian atas dilengkapi dengan pesan sambutan, diikuti oleh empat kartu informasi (summary cards) yang menyajikan data statistik real-time mengenai total pendaftar, pendaftar yang menunggu verifikasi, diterima, dan ditolak. Pada bagian bawah, terdapat visualisasi data berupa grafik tren pendaftaran dan diagram lingkaran (pie chart) asal sekolah, sehingga admin dapat memantau pergerakan pendaftaran secara cepat dan intuitif.

h. Tampilan Manajemen Konten Website
[ Sisipkan Gambar Manajemen Konten Website Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Manajemen Konten Website. Melalui halaman ini, admin dapat mengelola berbagai teks dan gambar yang ditampilkan pada halaman utama (landing page) publik, seperti informasi prestasi atau berita terbaru. Daftar konten disajikan dalam format baris yang terstruktur rapi, menampilkan tipe, isi konten ringkas, serta tombol aksi untuk mengedit atau menghapus data. Hal ini mempermudah proses pembaruan informasi sekolah secara dinamis.

i. Tampilan Data Pendaftar
[ Sisipkan Gambar Data Pendaftar Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Data Pendaftar. Ini adalah halaman operasional utama di mana admin dapat mengelola dan memverifikasi seluruh calon siswa baru. Antarmuka ini dilengkapi dengan fitur pencarian yang tangguh, penyaring (filter) status, serta navigasi tab untuk mengelompokkan pendaftar berdasarkan jalur pendaftaran (Semua, Reguler, Prestasi). Data disajikan dalam bentuk tabel komprehensif yang dilengkapi tombol aksi "Detail" untuk peninjauan berkas lebih lanjut.
