Penjelasan Class Diagram

Deskripsi Gambar: Class Diagram di atas menggambarkan struktur objek utama beserta relasi antar entitas pada Sistem Penerimaan Peserta Didik Baru (PPDB). Diagram ini terdiri dari 9 class (kelas objek) yang saling berelasi membentuk arsitektur data sistem secara keseluruhan.

Penjelasan Struktur Pewarisan (Inheritance):

Class Pengguna merupakan class induk (superclass) yang memiliki atribut umum seperti id, nama, email, kata_sandi, no_hp, dan peran, serta method dasar seperti login(), logout(), dan daftar(). Class ini diturunkan (inheritance) menjadi 3 subclass sesuai dengan peran pengguna dalam sistem, yaitu:

  • a. Admin Mengelola jalur pendaftaran, memverifikasi data pendaftar, melakukan plotting kelas, dan mengelola konten informasi publik.
  • b. Bendahara Memverifikasi bukti pembayaran pendaftar, mengelola komponen rincian biaya pendaftaran, dan mencetak rekapitulasi laporan keuangan.
  • c. Siswa Melengkapi pengisian biodata diri, mengunggah dokumen persyaratan, melakukan pembayaran, dan memantau status kelulusan pendaftaran.
