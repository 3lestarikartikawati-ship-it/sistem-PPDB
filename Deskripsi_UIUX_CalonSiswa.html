a. Tampilan Halaman Login
[ Sisipkan Gambar Halaman Login Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Login. Halaman ini adalah pintu gerbang utama bagi pendaftar (Calon Siswa) untuk mengakses sistem PPDB. Desain memfokuskan form login di tengah layar (center-aligned layout) yang berisi input Email, Password, opsi Ingat Saya, dan tombol eksekusi masuk, sehingga memberikan kesan profesional, sederhana, dan mudah digunakan.

b. Tampilan Dashboard Calon Siswa
[ Sisipkan Gambar Dashboard Calon Siswa Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Dashboard Calon Siswa. Halaman ini berfungsi sebagai pusat informasi bagi calon siswa setelah berhasil masuk ke dalam sistem. Desain mengadopsi tata letak dengan navigasi samping (sidebar) dan area konten utama yang menampilkan alur pendaftaran secara visual (progress tracker) beserta status verifikasi saat ini, sehingga pengguna dapat memantau tahapan pendaftaran dengan jelas.

c. Tampilan Formulir Pendaftaran
[ Sisipkan Gambar Formulir Pendaftaran Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Formulir Pendaftaran, khususnya pada bagian Data Pribadi. Halaman ini dirancang menggunakan sistem langkah bertahap (wizard) untuk memecah proses pengisian data yang panjang menjadi beberapa bagian yang lebih ringkas. Antarmuka menggunakan tata letak dua kolom untuk input data, yang bertujuan untuk memaksimalkan penggunaan ruang layar dan mengurangi kelelahan kognitif pengguna saat mengisi informasi diri.

d. Tampilan Formulir Upload Dokumen
[ Sisipkan Gambar Formulir Upload Dokumen Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk tahap Upload Dokumen pada proses pendaftaran. Desain membagi setiap kebutuhan dokumen seperti Pas Foto, Kartu Keluarga, dan Ijazah atau SKL ke dalam kotak (card) yang terpisah. Pendekatan ini disertai dengan informasi batasan ukuran dan format file yang diizinkan untuk memberikan panduan yang jelas dan mencegah kesalahan saat pengguna mengunggah berkas persyaratan.

e. Tampilan Halaman Pembayaran dan Daftar Ulang (Status Lunas / Terdaftar)
[ Sisipkan Gambar Halaman Pembayaran Status Lunas Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Pembayaran dan Daftar Ulang pada kondisi administrasi keuangan calon siswa telah lunas. Antarmuka ini dirancang untuk memberikan konfirmasi status secara jelas dan instan. Pada bagian atas, kartu utama menampilkan indikator status "STATUS: LUNAS / TERDAFTAR" dengan ikon centang sukses, pesan konfirmasi "Selamat! Administrasi pendaftaran ulang Anda telah lunas.", serta tombol panggilan aksi utama "Cetak Kuitansi Resmi" untuk mengunduh bukti transaksi sah. Pada bagian bawah, kartu Riwayat Pembayaran menyajikan tabel terstruktur yang memuat detail tanggal transaksi, metode pembayaran (MIDTRANS - BRI VIRTUAL ACCOUNT), nominal tagihan (Rp 300.000), serta badge indikator status Lunas.

g. Tampilan Pop-up Modal Gateway Pembayaran (Instruksi Virtual Account Midtrans)
[ Sisipkan Gambar Pop-up Modal Gateway Pembayaran Midtrans Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Pop-up Modal Gateway Pembayaran (Snap Midtrans) yang muncul ketika pengguna mengklik tombol bayar. Jendela modal tampil secara melayang di atas layar dengan latar belakang gelap teredup (backdrop blur) untuk memastikan fokus pengguna tetap pada proses transaksi. Modal ini menampilkan rincian total pembayaran (Rp 300.000), Order ID, serta hitung mundur waktu pembayaran (countdown timer "Pay within 23:58:45"). Di bagian tengah, terdapat instruksi lengkap transfer Bank BRI, nomor Virtual Account (contoh: 630230763723048267) dilengkapi tombol "Copy" untuk mempermudah penyalinan nomor VA, serta petunjuk tata cara pembayaran ("How to pay"). Tombol utama "Check status" terletak di bagian bawah modal untuk memverifikasi pembayaran dengan cepat setelah transfer dilakukan.

h. Tampilan Halaman Tanya Panitia
[ Sisipkan Gambar Halaman Tanya Panitia Di Sini ]

Tampilan di atas merupakan perancangan antarmuka untuk Halaman Tanya Panitia. Halaman ini berfungsi sebagai fitur layanan komunikasi (live chat) antara calon siswa dan panitia PPDB. Pada area utama, terdapat pesan instruksi yang jelas bagi pengguna untuk memulai percakapan baru jika mereka membutuhkan bantuan atau informasi tambahan selama proses pendaftaran.
