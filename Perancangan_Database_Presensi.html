Perancangan Basis Data

Perancangan basis data dilakukan untuk mendukung kebutuhan sistem dalam mencatat dan mengelola data absensi harian, manajemen siswa, penugasan guru, serta laporan rekapitulasi pada Sistem Informasi Presensi Sekolah. Basis data dirancang menggunakan MySQL, dan mencakup entitas utama seperti users, siswa, kelas, presensi, dan entitas pendukung lainnya.

1. Struktur Tabel

Berikut adalah rincian spesifikasi dari tabel-tabel utama yang digunakan di dalam sistem beserta kolom dan keterangan tipe datanya.

1. Tabel user

Nama Field Tipe Data Keterangan
id INT Primary Key, Auto Increment
name VARCHAR Nama lengkap pengguna
username VARCHAR Username untuk login pengguna
role ENUM Peran pengguna (Admin, Wali Kelas, Guru Mapel)
avatar VARCHAR Foto profil pengguna

2. Tabel siswa

Nama Field Tipe Data Keterangan
id INT Primary Key, Auto Increment
nis VARCHAR Nomor Induk Siswa
nama_siswa VARCHAR Nama lengkap siswa
status VARCHAR Status keaktifan siswa

3. Tabel kelas

Nama Field Tipe Data Keterangan
id INT Primary Key, Auto Increment
nama_kelas VARCHAR Nama rombongan belajar/kelas
semester VARCHAR Periode semester berjalan

4. Tabel presensi

Nama Field Tipe Data Keterangan
id INT Primary Key, Auto Increment
tanggal DATE Tanggal pelaksanaan presensi
status VARCHAR Status kehadiran (Hadir, Sakit, Izin, Alpa)
nama_mapel VARCHAR Mata pelajaran saat presensi dilakukan

5. Tabel pengajuan_presensi

Nama Field Tipe Data Keterangan
id INT Primary Key, Auto Increment
tipe VARCHAR Tipe pengajuan laporan/rekap
bulan VARCHAR Bulan pengajuan (contoh: Januari)
tahun VARCHAR Tahun pengajuan (contoh: 2024)
status VARCHAR Status validasi persetujuan

6. Tabel tugas_pengganti

Nama Field Tipe Data Keterangan
id INT Primary Key, Auto Increment
tanggal DATE Tanggal penugasan
alasan TEXT Alasan ketidakhadiran guru
status VARCHAR Status pelaksanaan tugas pengganti
