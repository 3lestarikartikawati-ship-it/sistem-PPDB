Dokumen Skenario Pengujian Sistem (Black Box Testing)

Sistem Informasi Penerimaan Peserta Didik Baru (PPDB)
SMP Muhammadiyah Kaliwiro

1. Pendahuluan & Metodologi Pengujian

Pengujian sistem ini menggunakan metode Black Box Testing (Pengujian Kotak Hitam). Pengujian ini berfokus pada pengujian persyaratan fungsionalitas sistem informasi PPDB SMP Muhammadiyah Kaliwiro tanpa perlu memperhatikan struktur kode internal program. Pengujian dilakukan untuk memastikan bahwa seluruh fungsi input, proses bisnis, integrasi gateway pembayaran Midtrans, manajemen data pendaftar, dan laporan output berjalan secara valid sesuai dengan spesifikasi kebutuhan yang telah ditetapkan.

Teknik pengujian Black Box yang diterapkan meliputi:

  • Equivalence Partitioning (EP): Pengujian dengan membagi domain masukan ke dalam kelas-kelas data valid dan tidak valid (misal: format email, ukuran file unggahan).
  • Boundary Value Analysis (BVA): Pengujian pada batas nilai masukan (misal: batas panjang password minimal 8 karakter, ukuran file maksimal 2 MB).
  • Decision Table Testing: Pengujian kombinasi syarat logika bisnis (misal: verifikasi berkas disetujui & administrasi pembayaran lunas untuk menentukan status penerimaan).
  • End-to-End Flow Testing: Pengujian skenario alur pendaftaran siswa secara utuh mulai dari registrasi akun hingga pencetakan kuitansi resmi dan pembagian kelas.

2. Ringkasan Aktor dan Lingkup Pengujian

Pengujian mencakup 4 (empat) peran/aktor pengguna utama dalam sistem PPDB:

  1. Pengunjung / Publik: Mengakses landing page, melihat informasi pendaftaran, FAQ interaktif, berita, dan mengirim pesan pertanyaan.
  2. Calon Siswa: Melakukan registrasi, login (tradisional & Google SSO), pengisian formulir wizard biodata, upload berkas, live chat panitia, pembayaran daftar ulang Midtrans, dan cetak dokumen (Bukti Pendaftaran & Kuitansi).
  3. Admin (Panitia PPDB): Mengelola data pendaftar, verifikasi berkas (split view), plotting rombongan belajar (kelas), CMS konten web, manajemen FAQ, membalas chat siswa, dan ekspor laporan.
  4. Bendahara: memantau dashboard keuangan, verifikasi pembayaran daftar ulang (manual & Midtrans), mengelola rincian biaya per jalur, konfigurasi rekening/QRIS sekolah, dan ekspor laporan keuangan.

4. Kesimpulan Hasil Pengujian

Berdasarkan seluruh skenario pengujian Black Box yang telah dilaksanakan pada Sistem Informasi Penerimaan Peserta Didik Baru (PPDB) SMP Muhammadiyah Kaliwiro untuk modul Autentikasi, Halaman Publik, Calon Siswa, Pembayaran Midtrans, Administrator, dan Bendahara, diperoleh kesimpulan sebagai berikut:

  1. Seluruh fungsi utama sistem (100% dari total skenario uji) berhasil lulus uji (PASS) dan beroperasi sesuai dengan spesifikasi fungsionalitas yang diharapkan.
  2. Validasi keamanan pada form input, pembatasan ukuran/format file berkas, otorisasi hak akses peran (middleware guard), serta penanganan error berjalan secara handal.
  3. Integrasi payment gateway Midtrans (Snap Pop-up, Webhook Callback, Sync Status) berjalan lancar dalam memproses transaksi pembayaran daftar ulang secara otomatis dan real-time.
  4. Sistem Siap (Ready) untuk diimplementasikan secara penuh pada proses Penerimaan Peserta Didik Baru (PPDB) SMP Muhammadiyah Kaliwiro.
